# 记忆翻牌 (Memory Game)

## v2.0 更新（2026）

- **四档难度**：入门 6 对 / 普通 8 对 / 困难 10 对 / 大师 12 对
- **连击奖励**：连续配对累计连击，失配清零；步数、用时、连击分别统计
- **最佳记录**：按难度分别持久化最少步数、最快用时与最高连击
- **翻转动画优化**：卡背扫光、配对弹跳、失配红色反馈
- **完美通关**：步数等于对数时触发专属彩蛋

**专属彩蛋**：完美通关解锁「过目不忘」；KONAMI 秘籍可偷看所有卡牌 1.6 秒。


经典的记忆翻牌配对游戏网页版，使用可爱的动物表情符号作为卡片图案。

## 功能

- **8 对卡片**：16 张卡片，8 种动物表情符号
- **翻牌配对**：点击翻开两张卡片，相同则配对成功
- **步数统计**：记录点击次数
- **配对进度**：显示已配对数 / 总对数
- **胜利提示**：全部配对成功显示恭喜信息
- **新游戏**：随时洗牌重新开始
- **中英文切换**：界面支持中文/英文
- **全屏模式**：沉浸式游戏体验
- **响应式设计**：适配桌面和移动端

## 使用方法

1. 用浏览器打开 `index.html`
2. 点击卡片翻开，记住位置
3. 连续翻开两张相同图案的卡片即配对成功
4. 在最少步数内完成全部 8 对配对
5. 点击"新游戏"重新开始

## 技术栈

纯 HTML/CSS/JavaScript。

## 彩蛋秘籍

所有小工具共用同一套彩蛋协议（EGG PROTOCOL v2.0）：

| 秘籍 | 效果 |
|------|------|
| `↑ ↑ ↓ ↓ ← → ← → B A` | 全屏彩带烟花 + 触发本应用专属彩蛋 |
| 连点页面标题 5 次 | 打开开发者模式面板 |
| 输入 `solcat` 后按回车 | 启用赛博朋克隐藏主题 |
| `Ctrl + Shift + T` | 切换赛博朋克隐藏主题 |
| 打开浏览器控制台 | 查看 SOLCAT ASCII 署名与解锁提示 |

> 提示：每个应用还藏有一个专属彩蛋，见上方 v2.0 更新说明。
