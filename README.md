# 记忆翻牌 (Memory Game)

经典的记忆翻牌配对游戏网页版，使用可爱的动物表情符号作为卡片图案。

## 功能

- **8 对卡片**：16 张卡片，8 种动物表情符号
- **翻牌配对**：点击翻开两张卡片，相同则配对成功
- **步数统计**：记录点击次数
- **配对进度**：显示已配对数 / 总对数
- **胜利提示**：全部配对成功显示恭喜信息
- **新游戏**：随时洗牌重新开始
- **中英文切换**：界面支持中文/英文
- **全屏模式**：沉浸式游戏体验
- **响应式设计**：适配桌面和移动端

## 使用方法

1. 用浏览器打开 `index.html`
2. 点击卡片翻开，记住位置
3. 连续翻开两张相同图案的卡片即配对成功
4. 在最少步数内完成全部 8 对配对
5. 点击"新游戏"重新开始

## 技术栈

纯 HTML/CSS/JavaScript。
